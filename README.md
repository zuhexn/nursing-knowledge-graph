# 护理知识图谱 · 静态交付站

本仓库是**护理知识图谱**的公开静态站点（GitHub Pages 托管 · 纯静态 · 无后端 · 无数据库）。

## 站点内容

| 路径 | 是什么 |
|---|---|
| `topic-01-kg/` | **题目一 · 可交互图谱页**（CT 增强检查护理风险）—— 力导向图 + 图例 + 节点详情 + 中英文关键词检索 |
| `topic-01-code/` | **题目一 · 运行代码下载页** |
| `topic-02-kg/` | **题目二 · 可交互图谱页**（恶心呕吐症状管理） |
| `topic-02-code/` | **题目二 · 运行代码下载页** |
| `index.html` | 站点落地页（两道题并列入口）|

> **两个题目是两份独立交付** —— 各自一个 URL、各自一套二维码，**页面内不做题目切换**。

## 图谱数据说明

- 图谱数据以 JSON 随站点发布（`data/<topicKey>-graph.json` + 同内容 `.js` 副本）；**检索在浏览器内完成**，页面不请求任何后端接口。
- 每个节点带**文献出处**（作者 / 标题 / 期刊 / 年份），可点开查看。
- 图谱内容依据公开发表的指南、共识、标准、系统评价与 Meta 分析等文献整理；**仅供护理知识科普与教学参考，不构成诊疗建议**。

## 本地运行

每个 `topic-0X-kg/` 目录都是**完整可独立运行**的目录：直接双击 `index.html` 即可打开（相对路径 · 无后端依赖）。

## 重新构建数据

各目录内附 `build.py` —— 对数据文件跑校验（节点 id 唯一 / 边两端存在 / 无重复边 / 检索词覆盖 / 文献完整性等）并导出数据。校验不过即非零退出。
