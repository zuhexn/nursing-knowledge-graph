⛔ 原脚本会 清空当前 Neo4j 库（这一行已在上方注释掉）、口令写死在代码里、Cypher 用字符串拼接、match(p),(q) 会把所有节点两两配对 —— 只适合本机一次性导入，不要直接用在有数据的库上，也不要把口令提交到公开仓库。

本交付的实际构建脚本是各构建包里的 build.py：只做数据校验与静态页面生成，不连数据库；在线图谱也不需要 Neo4j。随包的 Neo4j 导入包用 import.cypher（LOAD CSV + MERGE + 唯一约束）：可重复执行、不删数据、匹配时带上标签不会两两配对、跑完自带条数自检。
