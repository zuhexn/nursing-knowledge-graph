怎么用

1 · 直接看图谱

解压后双击 index.html 即可打开（全部资源相对路径 · 零后端 · 不联网）。

也可以把整个目录原样放进任意静态托管（对象存储 / CDN / 静态站点托管），无需任何服务端配置。

2 · 重新生成图谱

在解压后的目录里执行（Python 3.8+，只用标准库）：

python build.py --input data/topic-02-graph.json --out .

脚本会先跑一遍数据校验（节点 id 唯一 / 边两端存在 / 无重复边 / 节点 (类型, 名称) 唯一 / 检索词覆盖 / 文献完整性与四要素 / 不混题），任何一项不通过就非零退出并打印明细；全部通过才会重新生成页面与数据文件。

3 · 从 5 列表生成图谱数据

手里只有扁平的三元组表（类型, 名称, 关系, 目标类型, 目标名称 五列）时，先转成图谱数据文件：

python build.py --from-triples 我的三元组.csv --out-graph 我的图谱数据.json

包里已经带了一份现成的 5 列表（data/topic-02-triples.csv），可以先拿它试跑一遍：

python build.py --from-triples data/topic-02-triples.csv --out-graph 我的图谱数据.json

生成的 JSON 是骨架：节点与关系齐了，但别名、简介与文献出处需要补齐后再跑第 2 步的校验（校验不通过会逐条列出缺什么）。

⛔ 不编文献：没有真实出处的节点不要写进图谱 —— 校验脚本会按缺失项报出来。

数据与校验

构建包里的 build.py 会按同一套判据校验数据（两个题目各跑一遍，判据完全相同）；data/search-terms.json 是检索词覆盖检查的对照清单，随包提供，可自行重跑核对。

校验不通过的输出示例：

[FAIL] 5 客户检索词覆盖（数据名）
        未覆盖 2 条：荨麻疹 → 期望类型 SymptomSign; Meta分析 → evidence.type 缺「Meta分析」
